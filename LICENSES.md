# Licencias y componentes de terceros

Este documento registra los componentes externos conocidos. **No es una concesión de licencia ni sustituye la revisión de los términos originales.**

## Código y cuaderno de este repositorio

La licencia del código propio de `Mejorar_Imagenes_con_IA` todavía no se ha elegido. Hasta que se añada un archivo `LICENSE` con una decisión explícita, no debe asumirse que el código propio se ofrece bajo una licencia abierta concreta.

## CodeFormer

- Proyecto oficial: https://github.com/sczhou/CodeFormer
- El proyecto oficial identifica la licencia **NTU S-Lab License 1.0**.
- Antes de copiar, modificar, redistribuir o alojar componentes de CodeFormer, revisar el texto completo de la licencia en el repositorio oficial y comprobar qué usos permite.

## Real-ESRGAN

- Proyecto oficial: https://github.com/xinntao/Real-ESRGAN
- Revisar la licencia del repositorio oficial y los términos aplicables a los pesos/modelos antes de redistribuirlos.

## PyTorch y otras dependencias

El entorno puede instalar PyTorch, BasicSR, facexlib, gfpgan, lpips, OpenCV, Pillow, matplotlib y otras dependencias. Las versiones exactas y las licencias aplicables pueden cambiar según la instalación. Consultar los metadatos y las licencias de las versiones efectivamente instaladas antes de redistribuir un entorno o sus componentes.

## Pesos preentrenados

Los pesos de CodeFormer, Real-ESRGAN y otros modelos no se incluyen en este repositorio inicial. La licencia del código no debe asumirse automáticamente aplicable a todos los pesos, conjuntos de datos o modelos preentrenados.

## Cómo mantener este registro

Antes de integrar componentes externos en el repositorio:

1. Identificar el repositorio y la versión exacta.
2. Guardar o enlazar el texto de licencia correspondiente.
3. Revisar las condiciones de redistribución, modificación y uso comercial.
4. Mantener los avisos de copyright y atribución exigidos.
